# AFS Submissions Tool

This project is a Tkinter-based desktop application for managing submissions and related business processes. It includes features for file uploads, business document management, and (planned) email integration. The code is organized using the MVC pattern:

- **src/controllers/**: Application logic and event handling
- **src/models/**: Data models and business logic
- **src/views/**: Tkinter UI components

## Running the Application
1. Ensure you have Python 3.8+ installed.
2. Install dependencies:
   ```powershell
   pip install -r info/requirements.txt
   ```
3. Run the main application:
   ```powershell
   python src/main.py
   ```
